### 4. 100% OFFLINE CAPABILITY (AIRPLANE MODE READY)
The application must work 100% offline without internet after being installed on mobile:
- Configure `vite-plugin-pwa` with Workbox in `vite.config.ts`:
  * `globPatterns`: `['**/*.{js,css,html,ico,png,svg,webmanifest,json,jpg,jpeg,webp}']`
  * Pre-cache all core modules, clauses, fonts, and assets (30+ entries, ~2.8MB).
  * Auto-activation on install: `clientsClaim: true`, `skipWaiting: true`.
  * `navigateFallback: 'index.html'` to serve SPA on any route offline.
  * Caching strategies:
    - CacheFirst for documents, scripts, styles, images, and local fonts.
    - CacheFirst with dedicated cache for `https://fonts.googleapis.com` and `https://fonts.gstatic.com` (so Hind Siliguri and Plus Jakarta Sans render offline).
- In `src/main.tsx`, register service worker immediately in production using `virtual:pwa-register`.

### 5. ANDROID APK & GITHUB PAGES READINESS
To enable instant, error-free conversion into an Android APK via PWABuilder:
- Manifest File (`public/manifest.json`):
  * `"id": "./"`
  * `"start_url": "./"`
  * `"scope": "./"`
  * `"display": "standalone"`
  * `"theme_color": "#86efac"`
  * `"background_color": "#f8fafc"`
  * Icons: `pwa-192x192.png` (192x192, any), `pwa-512x512.png` (512x512, any), `pwa-maskable-512x512.png` (512x512, maskable) using relative paths (no leading slash so it works in any domain or GitHub Pages subdirectory like `/CMRC/`).
- Digital Asset Links:
  * Include `public/.well-known/assetlinks.json` configured for `package_name: "com.cmrc.contractdesk"` so Android hides the browser address bar in TWA mode.
- Static Hosting Compatibility:
  * Add `public/.nojekyll` to tell GitHub Pages to bypass Jekyll processing.
  * Add `public/404.html` (SPA fallback).
  * Set `base: './'` in `vite.config.ts`.
- In-App APK Modal (`AndroidApkModal.tsx`):
  * Provide 1-tap Chrome WebAPK install instructions.
  * Provide step-by-step GitHub Pages & PWABuilder export guide.
  * Provide downloadable ZIP packages:
    - `Pre-Built Web App (.ZIP)`: containing compiled `index.html`, `sw.js`, `.well-known`, and assets ready to drag into GitHub.
    - `Full Source Code (.ZIP)`: containing project code, automated `.github/workflows/deploy-pages.yml`, and `twa-manifest.json`.
